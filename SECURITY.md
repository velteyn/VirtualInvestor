# Security Policy

## Supported Versions

The `master` branch is the only supported version. There are no maintained
release lines — pull latest before reporting, and include the commit hash.

| Version | Supported          |
| ------- | ------------------ |
| master  | :white_check_mark: |
| older   | :x:                |

## Reporting a Vulnerability

**Do not open a public issue.** Report privately to the maintainer at
<ethanol-basin-yam@duck.com> with:

- what is affected (endpoint, module, or wire message),
- steps to reproduce or a proof of concept,
- the commit hash you tested.

You will get a confirmation within a week. If the report is accepted, the fix
lands on `master` and is credited in the commit message unless you ask
otherwise. The 90-day default disclosure clock applies: details may be
published once fixed, or 90 days after the report, whichever comes first.
